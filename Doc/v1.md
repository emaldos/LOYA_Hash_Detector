# LOYA Hash Detector v1
LOYA Hash Detector `1.0.0` is the first organized release of the hash identification tool.
It detects likely hash formats only. It does not crack hashes, verify passwords, call Hashcat, call John the Ripper, or run attack workflows.
## Features
- Regex-based full-input detection.
- Confidence scores sorted from strongest match to weakest match.
- Match reasons such as length, charset, prefix, separator, format, regex, and mapping source.
- Hashcat mode and John format hints where a safe mapping is known.
- Modern and common format coverage including bcrypt, Argon2, Django PBKDF2, Laravel bcrypt, Cisco type 5/8/9, NetNTLM, Kerberos, WPA, JWT, yescrypt, scrypt, and raw digest families.
- Single-hash mode, interactive mode, and file mode.
- Text and JSON output.
- CLI flags for top result count, strict filtering, quiet output, version display, logging, and debug exceptions.
- JSONL operational logging with `--log-file`.
- Graceful handling for file read errors and unexpected runtime errors.
## Usage
Run one hash:
```powershell
python .\LOYA_HASH_DETECTOR.py ae11fd697ec92c7c98de3fac23aba525
```
Run a modular hash:
```powershell
python .\LOYA_HASH_DETECTOR.py '$2b$12$abcdefghijklmnopqrstuuJr8oP9pL4gY3Yz7Q3QjzVvP6S7vO9fy'
```
Read hashes from a file:
```powershell
python .\LOYA_HASH_DETECTOR.py --file .\hashes.txt
```
Read hashes from a full file path without `--file`:
```powershell
python .\LOYA_HASH_DETECTOR.py D:\scripts\HashTypeDetector\hashes.txt
```
Print JSON:
```powershell
python .\LOYA_HASH_DETECTOR.py --json ae11fd697ec92c7c98de3fac23aba525
```
Limit results:
```powershell
python .\LOYA_HASH_DETECTOR.py --top 3 ae11fd697ec92c7c98de3fac23aba525
```
Show only stronger matches when possible:
```powershell
python .\LOYA_HASH_DETECTOR.py --strict ae11fd697ec92c7c98de3fac23aba525
```
Hide details in text mode:
```powershell
python .\LOYA_HASH_DETECTOR.py --quiet ae11fd697ec92c7c98de3fac23aba525
```
Write JSONL logs:
```powershell
python .\LOYA_HASH_DETECTOR.py --log-file .\loya.log ae11fd697ec92c7c98de3fac23aba525
```
Print version:
```powershell
python .\LOYA_HASH_DETECTOR.py --version
```
Open interactive menu:
```powershell
python .\LOYA_HASH_DETECTOR.py
```
Interactive options:
```text
1) HASH
2) File Directory
3) Exit
```
## Exit Codes
- `0`: success.
- `1`: invalid CLI usage or unexpected runtime error.
- `2`: file-related error such as missing, unreadable, or unwritable file.
